# Браслет «антистресс»

Школьный проект: браслет замечает, что пульс ребёнка поднялся и держится, и помогает успокоиться —
светофор 🟢🟡🔴, вибрация и дыхательное упражнение «4-4-4» (вдох 4 с — задержка 4 с — выдох 4 с).

## Железо

| Модуль | Подключение |
|---|---|
| Waveshare RP2040-Zero | — |
| OLED SSD1306 0.91" (128×32), стоит вертикально | I2C: SDA GP0, SCL GP1 |
| MAX30102 (пульс и температура, тыльная сторона запястья) | I2C |
| GY-521 (MPU6050/MPU6500 — движение) | I2C |
| Вибромодуль (IN / VCC / GND) | IN → GP28 |
| Адресный светодиод WS2812 | DIN → GP3 |

Все пины и настройки — в [`include/config.h`](include/config.h).

## Как работает

- **Пульс** — по ИК-сигналу MAX30102: полосовой фильтр, автокорреляция + отдельные удары, проверка качества
  сигнала. При движении руки и плохом контакте пульс не выдумывается — на экране «--» или бегущие точки.
- **Светофор** — общая норма 80 уд/мин: зелёный до 89, жёлтый с 90, красный со 105; пульс должен держаться
  повышенным 5 секунд. Показать стресс можно, часто подышав 20 секунд.
- **Бег — не стресс**: акселерометр видит движение (на экране «MOVE»), после него — отдых («REST»).
- **Температура** — оценка по датчику MAX30102 (кристалл подогревается платой, поэтому показываем около 36.6
  и только изменения), это не градусник.
- **Кнопка BOOT** — запустить или остановить упражнение.

## Сборка и прошивка (PlatformIO)

```sh
pio run -t upload                # прошивка браслета
pio run -e hwtest -t upload      # тест всего железа
pio run -e vibrotest -t upload   # тест вибромотора
pio test -e native               # тесты логики на компьютере
pio device monitor               # лог (115200), команда h — помощь
```

Первая заливка: зажать BOOT, подключить USB, отпустить.

Логика (пульс, движение, стресс, упражнение) лежит в [`lib/stress`](lib/stress) и не зависит от железа —
её проверяют тесты в [`test`](test), в том числе на настоящих записях сигнала с запястья (`test/data`).
